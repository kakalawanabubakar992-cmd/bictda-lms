# BICTDA LMS - Internship & Digital Skills Portal

Internship and Learning Management System for the **Borno State Information and
Communication Technology Development Agency (BICTDA)**, built for SIWES students and
NYSC corps members.

## Features
- Two sign-in portals: Interns (sign in with email, Intern ID or phone) and Facilitators (Facilitator ID)
- Sign up: interns register with full name, email, phone, programme and password (email and phone must be unique);
  facilitators register with a BICTDA-issued Facilitator ID, a password and the courses they offer
- Facilitators only see and manage the interns, attendance, assignments and grades of their own courses
- Passwords are always stored hashed (Werkzeug)
- SIWES and NYSC programmes with auto-generated IDs (`BICTDA-SIWES-001`, `BICTDA-NYSC-001`)
- One 6-month track of 4 courses for SIWES and NYSC, taken in order. The next course unlocks only when the final score is **50% or more**
- Attendance with punctuality credit: Punctual 100%, Late 50%, Absent 0%
- Assignments: facilitators post and grade them, interns submit them (text, link and/or a file:
  PDF, DOC, DOCX, TXT, HTML, CSS, JS, PY, IPYNB, max 5 MB). Files are stored in the database so they survive
  Render redeploys; only the intern and the facilitators of that course can download them
- My Results: interns see their final course results and print / save a landscape **Certificate of Completion**
  (BICTDA logo, full name, course, dates, signed by the Executive Secretary) for every course they pass
- Chart.js dashboards, works on phones and can be installed as an app (PWA)

## Course track (same for every SIWES and NYSC intern, 6 months)
| # | Course | Expected duration |
|---|---|---|
| 1 | Web Development | 1 month |
| 2 | Data Science & Python | 2 months |
| 3 | Machine Learning | 1 month |
| 4 | Cybersecurity | 2 months |

Courses are edited in one place: `COURSES` in `seed.py`. The pass mark is `PASS_MARK` in `models.py`.

## Tech stack
Python 3.12, Flask, Flask-Login, Flask-WTF, Flask-SQLAlchemy, SQLite (local) / PostgreSQL on Neon (live),
Tailwind CSS, Chart.js, Gunicorn, Render.

## Run locally
```bash
python -m venv venv
# Windows: venv\Scripts\activate     macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
copy .env.example .env               # macOS/Linux: cp .env.example .env
python seed.py                       # creates bictda_lms.db (programmes, courses, Facilitator IDs)
python app.py                        # open http://127.0.0.1:5000
```
There are no demo accounts: interns create their own accounts, and facilitators sign up with
a Facilitator ID issued by BICTDA (see below).

## Forgot password
Interns and facilitators click **Forgot password?** on the sign-in page and get an email with a reset link
(valid for 1 hour, works once). Emails are sent with Brevo's free web API because Render's free plan blocks
normal email (SMTP). On Render set `BREVO_API_KEY` and `MAIL_SENDER_EMAIL` (a sender address verified in Brevo).
On your laptop, without a key, the reset email is printed in the terminal instead.

## Install on a phone (PWA)
The LMS is a Progressive Web App:
- **Android (Chrome):** open the site, tap **Install app** (or menu **⋮ → Add to Home screen / Install app**).
- **iPhone (Safari):** open the site, tap **Share → Add to Home Screen**.

Updates are automatic: every `git push` deploys a new version, and installed apps show
"A new version of BICTDA LMS is available - Reload". If there is no internet, a friendly offline page is shown.
Installing needs HTTPS, so test it on the live Render link (or `http://127.0.0.1:5000` on your laptop).

## Deploy (Render + Neon, both free)
- **Database:** free PostgreSQL on [Neon](https://neon.com) (pooled connection string, Frankfurt region).
- **Web app:** free Render web service created from `render.yaml` (New -> Blueprint), Frankfurt region.
- `DATABASE_URL` is pasted into Render; `SECRET_KEY` is generated by Render.
- Every `git push` to `main` redeploys automatically, and installed phone apps show the update toast.
- Free Render services sleep after 15 minutes without visitors; the first visit after that takes about a minute.
- Never run `seed.py --reset` against Neon: live data is real data.

## Facilitator IDs
BICTDA issues Facilitator IDs. The admin adds them in one place: `ISSUED_FACILITATOR_IDS` in `seed.py`.
New IDs are saved to the database the next time the app starts. Each ID can be used to sign up only once.
You can also add a row straight into the `issued_facilitator_ids` table in Neon (Facilitator ID + full name).
